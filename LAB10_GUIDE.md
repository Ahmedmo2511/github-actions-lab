## 🎯 EXERCISE 1: BASIC PYTEST WORKFLOW

### Goal
Create a workflow that automatically runs Python tests whenever you push code or create a pull request.

### What You'll Create
- `scripts/math_utils.py` - Python module with add and subtract functions
- `scripts/test_math_utils.py` - Test file with pytest test cases
- `.github/workflows/pytest-exercise1.yml` - GitHub Actions workflow

### Step-by-Step

#### Step 1: Verify Python Files Exist
The following files are already created:

**scripts/math_utils.py:**
```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b
```

**scripts/test_math_utils.py:**
```python
from math_utils import add, subtract

def test_add():
    assert add(2, 3) == 5

def test_subtract():
    assert subtract(5, 3) == 2
```

#### Step 2: Workflow File - pytest-exercise1.yml
Location: `.github/workflows/pytest-exercise1.yml`

The workflow does:
1. **Checkout**: Gets your code
2. **Set up Python**: Installs Python 3.10
3. **Install dependencies**: Installs pytest
4. **Run pytest**: Executes tests in `scripts/` folder

```yaml
name: Run Automated Tests - Exercise 1

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install pytest

      - name: Run pytest
        run: pytest -v scripts/
```

#### Step 3: What Happens
1. You push code to GitHub
2. Workflow automatically triggers
3. GitHub runs tests on ubuntu-latest
4. You see results in Actions tab

#### Step 4: Expected Output
```
============================= test session starts ==============================
platform linux -- Python 3.10.x, pytest-x.x.x
collected 2 items

scripts/test_math_utils.py::test_add PASSED                           [ 50%]
scripts/test_math_utils.py::test_subtract PASSED                      [100%]

============================== 2 passed in 0.05s ===============================
```

## 🎯 EXERCISE 2: MATRIX STRATEGY

### Goal
Run the same tests on multiple operating systems at the same time.

### What Changes
Instead of running on just `ubuntu-latest`, the workflow now runs on:
- `ubuntu-latest` (Linux)
- `windows-latest` (Windows)
- `macos-latest` (macOS)

### The Matrix Strategy

```yaml
strategy:
  matrix:
    os: [ubuntu-latest, windows-latest, macos-latest]

runs-on: ${{ matrix.os }}
```

**How it works:**
- GitHub creates 3 separate jobs (one for each OS)
- Each job runs in parallel
- Each uses the same steps but different operating system
- All must pass for workflow to succeed

### File: pytest-exercise2.yml

Location: `.github/workflows/pytest-exercise2.yml`

The complete workflow:

```yaml
name: Run Automated Tests - Exercise 2 (Matrix)

on: [push, pull_request]

jobs:
  test:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]

    runs-on: ${{ matrix.os }}

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install pytest

      - name: Run pytest
        run: pytest -v scripts/
```

### What You'll See in Actions Tab
- **Test (ubuntu-latest)** - Status: ✅ Passed
- **Test (windows-latest)** - Status: ✅ Passed
- **Test (macos-latest)** - Status: ✅ Passed

All three run simultaneously!

### Why Use Matrix?
✅ Test on multiple platforms  
✅ Catch OS-specific bugs  
✅ Ensure compatibility  
✅ Professional CI/CD practice

## 🎯 EXERCISE 3: ARTIFACTS & TEST REPORTS

### Goal
Generate test reports and save them as artifacts for download.

### New Concepts

#### JUnit XML Report
- Standard test report format
- Generated by pytest
- Contains detailed test results
- Can be downloaded and analyzed

#### Artifacts
- Files saved from workflow run
- Downloadable from GitHub
- Persist after workflow completes
- Useful for reports, logs, builds

### File: pytest-exercise3.yml

Location: `.github/workflows/pytest-exercise3.yml`

Two new steps:

**Step 1: Generate Report**
```yaml
- name: Run pytest (generate junit xml)
  run: pytest -v scripts/ --junitxml=pytest-report.xml
```

This creates `pytest-report.xml` file with test results.

**Step 2: Upload Artifact**
```yaml
- name: Upload test report artifact
  uses: actions/upload-artifact@v4
  with:
    name: pytest-report_${{ matrix.os }}
    path: pytest-report.xml
```

This uploads the report for each OS. Example names:
- `pytest-report_ubuntu-latest`
- `pytest-report_windows-latest`
- `pytest-report_macos-latest`

### Complete Workflow

```yaml
name: Run Automated Tests - Exercise 3 (Artifacts)

on: [push, pull_request]

jobs:
  test:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]

    runs-on: ${{ matrix.os }}

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install pytest

      - name: Run pytest (generate junit xml)
        run: pytest -v scripts/ --junitxml=pytest-report.xml

      - name: Upload test report artifact
        uses: actions/upload-artifact@v4
        with:
          name: pytest-report_${{ matrix.os }}
          path: pytest-report.xml
```

### What You'll See

In Actions tab after workflow completes:
- Three jobs showing (ubuntu, windows, macos)
- At the bottom: **Artifacts** section
- Three downloadable files:
  - `pytest-report_ubuntu-latest`
  - `pytest-report_windows-latest`
  - `pytest-report_macos-latest`

### How to Download Artifacts

1. Go to Actions tab
2. Click on the workflow run
3. Scroll to bottom
4. Find "Artifacts" section
5. Click on artifact name to download
6. Extract ZIP file
7. View `pytest-report.xml` in text editor or browser

## 📋 KEY CONCEPTS

### pytest
- Python testing framework
- Finds test files: `test_*.py`
- Finds test functions: `test_*`
- Runs assertions: `assert condition`

### Matrix Strategy
- Runs job multiple times with different variables
- Each combination gets a separate job
- Can matrix by OS, Python version, Node version, etc.
- All must pass for workflow to succeed

### Artifacts
- Files saved from workflow
- Available for download
- Persist for 90 days by default
- Useful for reports, builds, logs

### JUnit XML
- Standard test report format
- Tool-agnostic
- Contains: passed, failed, skipped tests
- Can be viewed in various tools

---

## 🔄 HOW MATRIX WORKS

**Without Matrix** (3 sequential jobs):
```
Job 1 (ubuntu) → 2 min
Job 2 (windows) → 2 min  (waits for Job 1)
Job 3 (macos) → 2 min    (waits for Job 2)
Total time: 6 minutes
```

**With Matrix** (3 parallel jobs):
```
Job 1 (ubuntu) ⟹
Job 2 (windows) ⟹ All run simultaneously
Job 3 (macos) ⟹
Total time: 2 minutes
```

Matrix is much faster! ⚡

```bash
pytest
```
Finds and runs all tests

```bash
pytest -v
```

```bash
pytest scripts/test_math_utils.py::test_add
```

### Generate Report
```bash
pytest --junitxml=report.xml
```

### Combined
```bash
pytest -v scripts/ --junitxml=pytest-report.xml
```

Runs tests in `scripts/`, verbose, generates report
